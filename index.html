SSH Usage

Create pastes directly from your terminal - perfect for quick sharing from the command line

# Simple usage
cat myfile.py | ssh -p 2222 pasto.example.com

# Or with echo
echo "Hello, World!" | ssh -p 2222 pasto.example.com

# Login to link with web account
ssh -p 2222 pasto.example.com login

Quick Start

1

Clone Repository

Get the source code from GitHub

git clone https://github.com/ralsina/pasto.git
2

Install Dependencies

Install Crystal shards and dependencies

cd pasto && shards install
3

Run the Server

Start the Pasto web server

shards build && ./bin/pasto
4

Start Using

Open your browser to localhost:3000

open http://localhost:3000
