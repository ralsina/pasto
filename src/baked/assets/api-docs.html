🚀 Pasto API Documentation

Production-Ready REST API for Secure Pastebin Management

⚡ Quick Start

1. Get Your API Key

Generate a secure API key via SSH:

ssh -p 2222 your-pasto-server.com api-key create

2. Make Your First API Call

Test your authentication and create a paste:

# Get user info curl -H "Authorization: Bearer pasto_ak_your_api_key" \ https://your-pasto-server.com/api/v1/me # Create a paste curl -X POST \ -H "Authorization: Bearer pasto_ak_your_api_key" \ -H "Content-Type: application/json" \ -d '{ "content": "console.log(\"Hello from API!\");", "language": "javascript", "title": "API Test" }' \ https://your-pasto-server.com/api/v1/pastes

3. Available Endpoints

GET /api/v1/me GET /api/v1/pastes POST /api/v1/pastes GET /api/v1/pastes/:id GET /api/v1/pastes/:id/content DELETE /api/v1/pastes/:id
