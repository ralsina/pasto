# Changelog

All notable changes to the "pasto" extension will be documented in this file.

## [0.1.0] - 2025-12-26

### Added
- Initial release of Pasto VS Code extension
- Create pastes from selected text or entire files
- Fetch pastes by ID or URL
- Browse pastes in sidebar TreeView
- Secure API key storage using VS Code secrets API
- Support for self-hosted Pasto instances
- Auto-detect programming language from file extension
- Configurable default settings (private, expiry, language detection)
- Status bar integration for quick paste creation
- Context menu integration for right-click paste creation
- Inline actions in TreeView (copy URL, delete)
- Configuration via VS Code settings
