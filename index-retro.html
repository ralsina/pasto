SYSTEM FEATURES

Zero-Knowledge Encryption

True end-to-end encryption with Web Crypto API. Your encrypted pastes never touch the server in plain text.

Full SSH Interface

13 commands including paste, edit, delete, list, get, view, and SSH key management. Fully scriptable and pipe-friendly.

Burn After Reading

Self-destructing pastes that automatically delete after first view. Perfect for sharing sensitive one-time information.

321+ Syntax Themes

Massive theme library via Tartrazine. From Dracula to Monokai to GitHub, plus separate UI theming.

RESTful API

Full API with key-based authentication. Create, list, retrieve, update, and delete pastes programmatically.

Live Syntax Preview

Real-time syntax highlighting as you type with automatic language detection for 200+ languages.

Flexible Expiration

Set expiration times from 10 minutes to 1 month, or use view-once for instant deletion.

Private Pastes

Create private pastes visible only to you. Perfect for personal notes and snippets.

Markdown Rendering

Client-side markdown rendering with toggle between source and rendered view. Great for documentation.

User Accounts

Manage pastes across devices with user profiles. Edit, delete, and organize your paste history.

Crystal-Powered

Built with Crystal for blazing performance and low memory footprint. Fast compilation and runtime.

Fully Responsive

Beautiful on desktop, tablet, and mobile. Dark mode support built-in.

POWERFUL SSH INTERFACE (13 COMMANDS)

Full paste lifecycle management from your terminal. No web browser required.

# CREATE PASTES WITH OPTIONS
echo "Hello World" | ssh pasto.example.com
cat code.py | ssh pasto.example.com paste -l python -t "My Script"
echo "secret" | ssh pasto.example.com paste --encrypted --burn --expire 1h

# VIEW AND MANAGE PASTES
ssh pasto.example.com list                    # List all your pastes
ssh pasto.example.com get abc123 > file.txt   # Download paste content
ssh pasto.example.com info abc123             # Show paste metadata
cat new.txt | ssh pasto.example.com edit abc123  # Update content
ssh pasto.example.com delete abc123           # Remove paste

# API & SSH KEY MANAGEMENT
ssh pasto.example.com api-key create          # Generate API key
ssh pasto.example.com ssh-key list            # List SSH keys
ssh pasto.example.com login                   # Link to web account

# SEE ALL COMMANDS
ssh pasto.example.com help

QUICK START PROTOCOL

1

Clone Repository

Get the source code from GitHub

git clone https://github.com/ralsina/pasto.git
2

Install Dependencies

Install Crystal shards and dependencies

cd pasto && shards install
3

Run the Server

Start the Pasto web server

shards build && ./bin/pasto
4

Start Using

Open your browser to localhost:3000

open http://localhost:3000
